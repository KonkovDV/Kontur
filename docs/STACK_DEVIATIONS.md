# Отклонения от рекомендуемого стека

Ответ организатора от 26.09.2026 (пункт 1 таблицы) просит описать
отклонения. Обязательное поведение сохранено: REST/JSON, OpenAPI 3.0,
pull-модель с `process_id` и статусами, воспроизводимый локальный запуск,
журнал и сохранение результатов. Промышленный стек этой запиской не
фиксируется.

| В ТЗ | В репозитории | Что от этого не меняется |
|---|---|---|
| RabbitMQ | Поток `kontur-pipeline` в процессе API | Загрузка не ждёт L1–L7. Статус читается отдельно. Это не брокер. Confirm брокера не ACK ИАИС «РиН» |
| Next.js | React и Vite в `web/` | Сквозной экран инспектора. Отдельный экран на каждый из 12 модулей не требуется |
| Продуктивная ИАИС «РиН» | Outbox и inbox | На хакатоне достаточно mock. Подтверждение очереди не переводит процесс в `SYNCED` |
| УКЭП | Провайдера подписи нет | Ответ 27: отсутствие реальной подписи оценку не снижает. Mock успех/отзыв/ошибка ещё не сделан |
| Облачные LLM/OCR/VLM | Локальные Tesseract и веса PP-OCRv5 | Зачётный прогон не отправляет документы наружу |
| DWG | Расширение отклоняется | Ответ 10: обработчик DWG не требуется |
| Промышленный CI/CD | GitHub Actions и Docker Compose | Ответ 2: конкретная CI-платформа не является недопуском |

Гейты I/J/K/L этой таблицей не закрываются.
