# Двенадцать модулей

Нумерация как в составе системы ТЗ, §7. Отдельный экран на каждый модуль не требуется: организатор 26.09.2026 просит сквозной путь от объекта до протокола. Здесь — где этот путь лежит в коде.

| № | Модуль | Где | Сейчас |
|---|---|---|---|
| 1 | Загрузка и разбор | `application/intake.py`, `process_pipeline.py`, `passport.py`, `pdfium_tokens.py` | PDF, DOCX, XML и zip. Пустой текстовый слой читает локальный OCR. Штамп на крупном листе — правый нижний угол. 7z, rar и DWG в сверку не входят |
| 2 | Сравнение и протокол | `evaluate.py`, `protocol.py`, `protocol_export.py` | Карточка и протокол JSON, DOCX, XML, PDF. В карточке есть SHA-256, статус утверждения и причина решения. Рабочий экстрактор у 59 правил из 132, остальные строки в ответе есть и нарушение не собирают |
| 3 | Верификация | `review.py`, `web/` | Очередь, карточка трёх стадий, подтверждение и отказ с причиной, финализация |
| 4 | Дообучение | `audit` решений | Решения инспектора пишутся в журнал. Отдельного переобучения модели нет |
| 5 | Свободный поиск | `provision_clause.py`, `suspicion.py` | Фраза «пом. N предусмотрен элемент» даёт гипотезу `SUSPICION`, не строку матрицы |
| 6 | РиН | `outbox.py`, `rin_client.py` | Финализированный протокол встаёт в очередь. HTTP 5xx повторяется, HTTP 4xx останавливает попытку. Живого приёмника и УКЭП нет |
| 7 | Экран инспектора | `web/src/LiveWorkspace.tsx` | Один сквозной экран: комплект, находки, карточка, протокол |
| 8 | Матрица | `data/matrix/` | 132 правила данными. Ссылка на норму в карточке вердикт не меняет |
| 9 | Аудит | `infrastructure/db/audit_store.py`, `GET /audit` | Загрузка, выбор эталона, решение, финализация |
| 10 | Отчёт по дообучению | — | Нет |
| 11 | Наблюдение | `healthz`, логи шлюза | Прогон GitHub Actions на `/status`: p95 18,26 мс, n=6000. Grafana и ELK нет |
| 12 | Ошибки загрузки | `intake.py`, шлюз | Формат, повреждение, 50 МБ на файл, 200 МБ на пакет, таймаут разбора, zip-бомба |

Пять сессий инспекторов и frozen validation в эту таблицу не входят: это гейты K и J.
