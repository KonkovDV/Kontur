## Авторитетные факты из колла 18.09.2026 (ТЗ v1.1)

> Факты ниже зафиксированы с записи колла с организатором ЛТЦ. Не официальный ответ
> (артефакт отправки отсутствует), но авторитетный дополнительный контекст.

- **ИАИС «РиН»** = только endpoint на нашей стороне; РиН забирает данные сам (пулл-модель). Полная интеграция вне скоупа хакатона.
- **Авторизация** не является критерием оценки хакатона; любой Bearer-токен достаточен.
- **Отсутствие документа ≠ нарушение**: показывать неполный комплект (инвариант 4 соблюдён).
- **Массовая верификация через checkbox** допустима; отклонение должно быть поштучным (показать позицию отклонения).
- Формат `frozen_val.jsonl` будет опубликован организатором; наш гейт-тест совместим.
- **ТЗ v1.1 авторитетнее v1.0** (версия v1.0 архивирована).
