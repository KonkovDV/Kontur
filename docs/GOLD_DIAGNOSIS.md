# Диагностика TRAIN_PUBLIC, 24.09.2026

Прогон `python -m kontur.evaluation.train_public` после ADR-0014. Снимок
`data/dataset/train_public_engineering.json` — выгрузка скрипта, `observed_at`
2026-09-24. Это не порог ТЗ и не закрытие гейта J.

Загружены два файла объекта `OBJ-TYUMENSKAYA-5-GOLD-SEED`: F0171 как ПД,
F0201 как РД. Ошибок разбора нет. В публичном gold нет поля помещения:
`gold_inventory.json` хранит `check_id`, `object_id`, `parameter_code`.
