# Протокол юзабилити (ТЗ п. 9.3)

Форма замера для RT-2609-21. Находка закрывается только после сессии с 5
инспекторами, не по факту появления этого файла или UI-рекордера. Проводится
до гейта K (26.09.2026).

## Целевые метрики

| Показатель | Порог ТЗ | Как фиксируется |
|---|---|---|
| Время на протокол (один объект) | ≤ 30 мин | `session_started_at` / `session_finished_at` в JSON и секундомер наблюдателя |
| Кликов до решения по одной находке | ≤ 3 | `clicks_to_decision` в JSON-рекордере |
| Ошибок навигации | — | устная ремарка / экранная запись |

## Состав участников

5 инспекторов с разным опытом работы с ПД/РД/ИД.  
Задача: обработать одинаковый тестовый комплект (учебный объект,
не TRAIN_PUBLIC и не скрытый тест).

## Сценарий сессии

1. **Инструктаж ≤ 5 мин** — интерфейс, цель, что считается «решением».
2. Ввести обезличенный код участника; не вводить ФИО и контакты.
3. **Загрузка** тестового пакета через UI.
4. **Проверка 5 находок**: минимум 1 числовая, 1 текстовая, 1 со статусом
   `MISSING_EVIDENCE`.
5. **Финализация** протокола.
6. Скачать JSON-протокол `kontur-usability-v1` и передать наблюдателю.
7. **Экспорт** предметного протокола и сверка структуры с Приложением 2 ТЗ.

Текущий UI предоставляет учебную очередь из пяти находок и записывает только
время и клики по действиям. Это инженерный инструмент замера, а не результат
Gate K и не замена наблюдателю.

Заполняется наблюдателем по JSON и экранной записи. Результаты фиксируются в
`docs/USABILITY_RESULTS.md`; сырые JSON не коммитятся, если в них появились
персональные или служебные данные.

## Критерий успеха

Все 5 инспекторов: время ≤ 30 мин **и** максимум кликов до решения каждой
находки ≤ 3. Среднее приводится как дополнительная метрика, но не скрывает
единичный провал.  
Хотя бы один провал → задача в backlog до гейта M (28.09).

## Связанные артефакты

- `web/src/usability.ts` — стабильная схема и расчёт метрик;
- `web/src/App.tsx` — учебная очередь и скачивание JSON;
- Red Team: RT-2609-21 (остаётся открытой до пяти сессий);
- Gate K (26.09): UI ≤ 3 кликов на находку; протокол по Приложению 2;
  dry run 132 параметра ≤ 30 мин.
