1. Статусы: `VIOLATION_PRESENT/NO_VIOLATION/MISSING_DOCUMENT/COMPARISON_IMPOSSIBLE` + `protocol_status` (OK/WARNING/CRITICAL/...) ↔ внутренние `FindingStatus` + `review_priority`.

4. Критичность: `criticality` ≠ `review_priority`; хранить обе.
5. ИД-тройственность: попарная ПД↔РД валидна без ИД.
