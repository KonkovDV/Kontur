## 1. Цель и критерий успеха

К моменту freeze 29.09.2026 23:59 МСК предъявить воспроизводимый вертикальный
срез:

`пакет ПД/РД/ИД → идентичность и актуальная редакция → локализованное извлечение
→ исполняемое правило → CANDIDATE/безопасный отказ → решение инспектора →
версионированный протокол → mock-доставка`.

Успех определяется не числом строк кода и не количеством declared rules, а
одновременным выполнением пяти условий:

1. холодный запуск и пакетный прогон воспроизводимы;
2. каждая демонстрируемая предметная находка имеет полную evidence chain;
3. автомат не создаёт `CONFIRMED_VIOLATION`;
4. измерения публикуются только с размером выборки, статусом corpus и интервалом;
5. известные пробелы остаются видимыми и не маскируются документацией.

- TEST_HIDDEN, Речников и закрытый пакет не открывать для threshold, prompt,
  regex или выбора модели.
- `CONFIRMED_VIOLATION` создаёт только инспектор.
- Не переводить правило в `executable` без рабочего extractor и fixture.
- Не угадывать стадию `RD_ID_MIXED`, revision order или единицу голого числа.
- Не добавлять до freeze OIDC/JWKS, TLS, RabbitMQ 4.x, observability stack,

- Правки выполняются только через GitHub Agent Bus v2: issue → claim → branch →

## 5. Workstreams

Каждая задача задаётся как `requirement → artifact → test → metric → stop`.

### WS-A. Ground truth и измерения — P0, local + человек

**Requirement:** отделить инженерный прогон от приёмочного вывода.

**Artifacts:** corpus manifest; object-level split; human-verified OCR fields;
матрица positive/negative/abstain cases; hashes; scoring report с n и 95% CI.

**Tests:** отсутствие hidden object IDs; hash stability; train/validation
isolation по object_id; scorer на synthetic sanity set.

**Metrics:** Character Accuracy, Exact Match, evidence localization,
Precision/Recall/F1/FPR публикуются как измерения только с corpus status, n,
coverage/abstention и interval. Пороги ТЗ помечаются как приёмочные минимумы.

**Stop:** нет frozen corpus или human labels — публиковать только engineering
result; Gate I/J остаются открыты.

### WS-B. Конкурсные вертикальные срезы — P0, local

Выбранный набор должен покрывать разные типы доказательств, а не максимальное
число похожих regex:

- `PZ-001`: числовое значение из таблицы;
- `KR-055`: enum/class;
- `AR-041`: размер с единицей;
- `AR-040`: одна измеримая пара штрихов;
- `IOS4-078/079`: число + помещение + безопасный отказ;
- `SPZU-025/026`: площадь одного контура;
- `IOS2-071`: element table по маркам.

**Artifacts:** на каждое правило — equal, valid mismatch, missing source,
revision conflict, unsupported/ambiguous evidence; protocol card.

**Tests:** реальные pipeline functions и PDF fixtures; никаких mock-only tests,
`assert True`, слабого `or` или skip на assertion path.

**Metrics:** доля кейсов с полной evidence chain; отдельно outcome distribution
`CANDIDATE/LOW_QUALITY/ABSTAIN/MISSING_EVIDENCE`.

**Stop:** неоднозначная геометрия, несколько контуров/пар или конфликт чтений →
безопасный статус, не forced candidate.

### WS-C. Revision, identity и pairing — P0, cloud-ok

**Requirement:** устаревший или чужой том никогда не становится эталоном.

**Artifacts:** regression matrix для identity tuple и revision graph;
manifest выбора эталона с reason.

**Tests:** successor; две головы одного шифра; два разных шифра; `не утв.`;
inspector select; mixed stage; порядок upload не влияет.

**Metric:** deterministic selection для однозначных fixtures; все конфликты дают
`CLARIFICATION_REQUIRED`.

**Stop:** не выводить порядок из текста `ред. N` без явной связи.

### WS-D. Evidence UI и Gate K — P0, local + человек

**Requirement:** инспектор видит expected/actual, ПД/РД/ИД, revision reason,
страницу и polygon до решения.

**Artifacts:** 5 session JSON; агрегированный `USABILITY_RESULTS.md`; перечень
ошибок интерфейса; видео демо.

**Tests:** rotated page overlay; missing ID pane; reject reason mandatory;
forbidden transitions; audit record.

**Metrics:** время цикла, клики, корректность решений, причины отклонений,
следование ошибочному совету. Целевые значения ТЗ остаются целями приёмки.

**Stop:** recorder без пяти сессий не закрывает Gate K; состав группы описывается
честно.

### WS-E. Protocol и submission — P0, cloud-ok

**Requirement:** JSON/DOCX/XML/PDF представляют одну семантику.

**Artifacts:** canonical JSON; deterministic exports; run manifest; SHA image;
input manifest hash; evidence pack.

**Tests:** обязательные разделы; same finding IDs/values/polygons во всех
форматах; finalize immutable; object failure не уничтожает run manifest.

**Metric:** 100% демонстрируемых findings имеют одинаковую canonical identity
во всех exports. Это internal consistency, не метрика качества модели.

**Stop:** отсутствует provenance — экспорт падает или даёт безопасный статус,
но не создаёт подтверждённое нарушение.

### WS-F. OCR reliability — P1, local

**Requirement:** raster path не подменяет vector path и умеет отказаться.

**Artifacts:** eslav/Tesseract bake-off; rotation matrix; key-field normalize;
engine provenance; bounded worker payload.

**Tests:** `/Rotate` 0/90/180/270; empty raster; conflicting reads; Cyrillic
cipher; no whole-PDF transfer to OCR workers; Windows in-process fallback.

**Metric:** engineering CA/EM с n и interval; отдельно raster GOLD, если он
появится.

**Stop:** нет human raster labels — статус остаётся `MEASURED`; выбор удобного
reader при disagreement запрещён.

### WS-G. Agent bus и context integrity — P1, cloud-ok

**Requirement:** агент получает один актуальный protocol и не принимает
исторический snapshot за live state.

**Artifacts:** единый `kontur.agent_bus.v2`; plan; regression test; handoff
comment; ссылки на generated snapshots.

**Tests:** implementer-agent не содержит v1; plan и canonical docs существуют;
claims-lint не допускает ложных заявлений.

**Metric:** zero protocol-version contradictions в tracked agent instructions.

**Stop:** не строить IssueOps service до freeze; claim остаётся best-effort и
его TOCTOU-риск документирован.

## 8. Release gates

### R0 — semantic safety

- machine verdict отсутствует;
- missing/uncertain data не превращается в violation;
- revision conflict fail-closed.

### R1 — evidence integrity

- SHA, page, polygon, stage, cipher, revision и role expected/actual сохранены;
- rotated page overlay совпадает с rendered image.

### R2 — reproducibility

- cold start documented;
- package runner сохраняет manifest даже при partial object failure;
- git/image/input hashes зафиксированы.

### R3 — measurement honesty

- corpus status и n присутствуют;
- 95% CI и coverage/abstention присутствуют;
- acceptance threshold не объявлен достигнутым без frozen validation.

### R4 — inspector workflow

- transitions и audit корректны;
- rejection reason обязателен;
- Gate K закрывается только фактическими sessions и по правилам ТЗ.

## 9. Risk register

| Риск | Ранний сигнал | Containment | Stop condition |
|---|---|---|---|
| Hidden-test leakage | test object ID в tracked data | quarantine test | удалить данные, не использовать результат |
| False candidate | нет evidence/ambiguous geometry | fail-closed status | не экспортировать как candidate |
| Revision mismatch | несколько heads/identity conflict | clarification | не сравнивать |
| OCR disagreement | readers дают разные number/cipher | ABSTAIN | не выбирать reader |
| Snapshot drift | counts/gates расходятся | generated snapshots + regression | не цитировать historical issue |
| Fake green CI | runner_id=0/steps=[] | real-CI verification | PR остаётся draft |
| Agent race | два claims | reread + earlier event wins | проигравший не push |
| Scope creep | новый production service | freeze label | перенос после подачи |
| Demo-only overfit | threshold меняется после gold | preregister | откатить изменение |
| Export divergence | разные IDs/values | canonical JSON | блокировать freeze |
