## Что говорит SOTA на сентябрь 2026 — и почему стек не менять

Проверено 28.09.2026 по открытым источникам. Полная записка —
[`RESEARCH_OSINT_2026.md`](RESEARCH_OSINT_2026.md). Это не замер Контура.

- PP-OCRv6 (PaddleOCR 3.7.0, 11.06.2026) русский не распознаёт. Для кириллицы
  остаётся eslav PP-OCRv5. Движок не обновлять.
- Лидеры OmniDocBench v1.6 (PaddleOCR-VL-1.6, MinerU2.5-Pro, Qwen3-VL) — корпус
  в основном китайско-английский, VLM-бэкенды требуют GPU. На зачётный офлайн-прогон
  не переносить. Цифры бенчмарка точностью Контура не называть.
- Marker/Surya/Chandra: веса с ограничением по выручке и запретом конкурирующего
  продукта. Для госзаказчика не брать.
- AECV-Bench (arXiv:2601.04819, январь 2026): в триаже матрицы средний
  exact-match подсчёта около 0,39–0,51, двери и окна у сильнейшей модели
  0,39 и 0,34. В `executable` не переводить.
- Проверка ограничений с доказательствами (arXiv 2607.29058, июль 2026) на новых
  проектах теряет выигрыш и даёт ложные «соответствует». Аргумент питча: вердикт
  у инспектора, разбиение по `object_id`.

  вторичным источникам (xml1.ru, ivanovoexpert). Официальная страница Минстроя

  Полный разбор 01.07 до дедлайна не писать.
- Облачные OCR/VLM API в зачётный прогон нельзя (ответ 23).
