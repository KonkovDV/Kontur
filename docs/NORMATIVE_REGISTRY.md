# Нормативный реестр и юридическая проверка правил

## Два слоя, которые нельзя смешивать

- `organizer_matrix_version` — контракт соревнования. По нему считается вердикт
  на скрытом тесте, даже если норма устарела.
- `current_normative_overlay` — действующая редакция. Показывается инспектору
  как предупреждение, не меняет вердикт контракта.

## Поля записи норматива

`issuer`, `act_type`, `number`, `date`, `revision`, `url`, структурная ссылка
(статья/пункт/таблица/приложение), `effective_from`, `effective_to`,
территория, тип объекта, обязательность (закон / подзаконный акт /
обязательный перечень / добровольный стандарт / контракт), применимость к
ПД/РД/ИД, машинно проверяемая часть, часть для эксперта, legal fixture с
ожидаемым результатом, дата и автор последней юридической проверки.

## Fail closed

Если источник утрачен, редакции конфликтуют или применимость не доказана,
система не создаёт нарушение — только `CLARIFICATION_REQUIRED`.

Автомат **не** сравнивает проект с СНиП: overlay не пишет `finding_status`
(ADR-0006).
