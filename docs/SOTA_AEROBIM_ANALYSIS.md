# SOTA: донор AeroBIM и разбор ТЗ

Источник идей: локальный `C:\AeroBIM` (коммит-ориентир `98fd92c`) и черновик
разбора аудио с организатором. Это **не** официальный ответ: в репозитории
нет артефакта отправки. Код и статусы Контура первичнее любых слайдов.

PR #4 содержал тот же текст одной строкой base64 и предлагал автомату
ставить `NEGATIVE_VERIFIED`. Этот файл — исправленная версия.

## Что переносится в Контур

1. **Сверка — ПД ↔ РД ↔ ИД, не проект против СНиП.** Таблица 4 п. 9.5 ТЗ
   («потолок 2,4 против 2,5 по СНиП») — ловушка. Вердикт матрицы организатора
   не подменяется overlay действующих норм (ADR-0006).
2. **Нет документа ≠ нарушение.** Комплектность отдельно, находка отдельно.
3. **Детерминированное ядро, LLM — sidecar.** Модель не пишет `finding_status`
   (ADR-0001). Сбой `llm_advisory` не валит комплект (`domain/capabilities.py`).
4. **Provenance.** Предметная находка без файла, SHA-256, страницы и polygon
   не сохраняется (ADR-0002).
5. **Эталон — последняя утверждённая редакция.** Неутверждённая, даже новее,
   не смещает эталон (`revision_resolver.py`, ADR-0003).
6. **Повтор входа — тот же ключ.** `comparison_key` стабилизирует
   `evidence_group_id`.

## Что в черновике SOTA было неверно

```text
неверно: параметр не найден в загруженном документе → NEGATIVE_VERIFIED
верно:   документ стадии отсутствует → MISSING_EVIDENCE
         документ есть, значение не извлечено → LOW_QUALITY / ABSTAIN
         NEGATIVE_VERIFIED и CONFIRMED_VIOLATION пишет только инспектор
```

`NEGATIVE_VERIFIED` — человеческий статус. Автомат при совпадении пишет
внутренний `AUTO_NO_DIFFERENCE`.

## Целевой конвейер (ещё не весь исполняется)

```text
пакет PDF → профиль/токены → паспорт → резолвер редакции
         → правило матрицы → provenance → находка
         → HITL (три панели ПД/РД/ИД, ≤3 сознательных действия)
         → протокол
```

Сейчас executable — `PZ-001` на токенах страницы. Остальные 131 строка
матрицы — `extractor_missing`. OCR bake-off, детектор скрытого текста,
DAO процессов и модуль `SUSPICION` — в [KNOWN_GAPS.md](KNOWN_GAPS.md).

## Перенос 08.10.2026 из кода AeroBIM

Изучен `github.com/KonkovDV/AeroBIM` (донор, не чужой контест) и открытые
контуры рядом: сверка полей с ε по единицам, вектор страницы без подсчёта
символов, матрица зависимостей документов. В Контур перенесено то, что
чинит пару томов, а не чужой контур IFC/коллизий.

`section_pairing.py` AeroBIM сводит «ОВ», «ОВ2.1», «отопление», «вентиляция»
и HVAC к одной марке. Контур так делал только для шифра. Теперь то же самое
делает `_kind_aliases`: индекс марки и словесный синоним. Папка «Вентиляция»
даёт дисциплину ОВ, как папка «Отопление». Чужой раздел по-прежнему не
отдаёт число. Подсчёт дверей по прямоугольникам не переносился: у AeroBIM
это кандидат эвристики, не проверенный счёт, и Контур такие правила
оставляет `extractor_missing`.
