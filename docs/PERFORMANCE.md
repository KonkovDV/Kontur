## Три разные вещи, которые нельзя мерить одной цифрой

1. **Сетевая загрузка** — 10 × 50 МБ за 2 минуты. Ограничение ТЗ относится к
   приёму файлов и постановке в очередь, а не к анализу.
2. **Обработка** — асинхронный pull по `process_id` (ТЗ п. 1.4). Тяжёлые
   стадии уходят в очередь; их длительность мерится отдельно по стадиям.
3. **Отклик API** — p95 ≤ 200 мс считается по синхронным ручкам. Эндпоинт,
   который ждёт распознавание, в этот бюджет не попадает по определению.

Смешивание этих трёх чисел — самый простой способ получить красивую цифру и
провалить приёмку, поэтому в отчёте они всегда раздельно.

## Методика прогона

- Gate L: 100 VU, 60 секунд, polling раз в секунду; setup-upload не входит в
  tagged latency.
- Расширенный сценарий приёмки: отдельные профили «загрузка», «просмотр
  находок», «верификация», «выгрузка протокола».
- Данные — из реальной поставки (см. [`DATASET_PACKAGE.md`](DATASET_PACKAGE.md)):
  доля растровых листов и распределение объёма документов берутся по
  инвентаризации, а не из синтетики.
- Стенд фиксируется в отчёте (CPU, RAM, GPU, тип диска). Без этого числа
  несопоставимы между прогонами.
- Каждый прогон пишет git SHA, `dataset_version`, `matrix_version`,
  `model_version`, `input_manifest_hash`.
- Публикуются p50/p95/p99 и размер выборки. Лучший одиночный прогон не
  публикуется никогда.
- Пункты 12–14 на локальном демо не подтверждаются: это требования к
  промышленной эксплуатации. В рамках хакатона фиксируется только архитектурное
  решение (репликация, резервное копирование, порядок восстановления).

## Ожидаемые узкие места

| Место | Почему | Что делаем |
|---|---|---|
| Рендер страниц | крупные растровые чертежи | кеш по `file_hash + page + dpi + preprocessing_version`, рендер по требованию |
| Распознавание | 500-страничные комплекты | постранично, параллельно, с приоритетом нужных листов |
| Матрица 132 правил | правила × документы × редакции | параллелизация по правилам, ранний отказ на L0–L5 |
| Синхронные ручки | ожидание тяжёлых стадий | очередь + pull статуса, никаких долгих синхронных вызовов |
