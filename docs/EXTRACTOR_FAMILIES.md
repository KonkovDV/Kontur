# Семейства экстракторов

PR #82 добавляет детерминированную поддержку двух семейств матрицы:

- `exact_field` — текстовое поле с явным `extractor.regex` или `value_regex`;
- `presence` — наличие текстового якоря в источнике.

## Безопасные границы

`exact_field` не угадывает границы многочастного значения. Если в правиле нет
явного шаблона значения, результат — `LOW_QUALITY`, а не автоматически
извлечённое поле.

`presence` подтверждает только найденное наличие. Отсутствие токена не является
самостоятельным доказательством нарушения: без отрицательного доказательства
результат остаётся `LOW_QUALITY`/`MISSING_EVIDENCE`.

Оба семейства сохраняют `file_id`, SHA-256, страницу, polygon и
`evidence_group_id`. Автоматический контур не пишет `CONFIRMED_VIOLATION`.

## Покрытие матрицы

Наличие общего экстрактора не переводит все правила семейства в
`executable`. Правило повышается только после отдельной fixture, проверки типа
доказательства и E2E-прогона. Графические и пространственные признаки не
становятся текстовыми только из-за совпавшей подписи.

PR не закрывает Gate J и не является заявлением о покрытии `132/132`.

## Поштучный триаж 28 правил

Общий экстрактор — не основание для повышения покрытия. Все 28 правил семейств
`exact_field` и `presence` разобраны по одному: какой вид доказательства реально
требуется по источникам ПД и РД из Приложения 1. Решение и причина по каждому
коду — [`data/matrix/family_triage.json`](../data/matrix/family_triage.json),
разбор — [`EXTRACTOR_FAMILY_TRIAGE.md`](EXTRACTOR_FAMILY_TRIAGE.md).

Итог: 4 правила переведены в `executable` (закрытые текстовые шаблоны), 1 — в
`advisory` (`presence` не способен выдать `CANDIDATE`), 4 — в `source_missing`
(доказательство во внешнем реестре, а не в пакете ПД/РД/ИД), 19 остались
`extractor_missing` с указанным `target_extractor`.

Гейт покрытия закреплён в движке: `_downgrade_for_coverage` в `evaluate.py`
понижает `CANDIDATE` до `low_quality` для покрытий `advisory`, `source_missing`,
`not_applicable`, сохраняя `expected` / `actual` / `delta` / `evidence_refs`.
Сработавший экстрактор не даёт права на обвинение, если покрытие честно
объявлено неполным.
