## 5. Murder Board / Red Team / роли

### Юрист
- Контур сверяет **документы стадий**, не выдаёт юридическое «соответствует СП».
  Иначе конкуренция с экспертизой и риск подмены заключения.
- Цифровой нормоконтроль и TimDoc живут в зоне «норма ↔ документ». Контур
  должен на питче явно сказать ADR-0006 одним слайдом.

### Банкир / заказчик (Мосгосстройнадзор)
- Ценность: сокращение камеральных часов инспектора + трассируемый протокол в РиН.
- Пилот XML ИД (Слободчиков) — стык: Контур должен уметь `ACCEPTED_UNPARSED` →
  парсер XML, когда корпус появится (уже в RESEARCH_OSINT).

### ИБ / безопасник
- Офлайн и запрет облачных VLM — уже сильнее TimDoc/RomanAI (облако по умолчанию).
- Коллегиум: on-prem + LLM-agnostic — ориентир для слайда ИБ.
- Любой импорт ClashControl/bimdiff кода = лицензионная мина (SSPL/AGPL).

### Пользователь (инспектор)
- Три панели ПД/РД/ИД + ≤3 действия (SOTA AeroBIM) — удерживать.
- У финалистов нет публичных UX — преимущество демо-стенда Контура.

### Триаж
| Находка | Severity | Действие |
|---|---|---|
| Финалисты почти без OSINT-следа | info | Мониторинг кабинета ЛЦТ; не тратить спринт на охоту |
| Цифровой нормоконтроль путают с №10 | medium | Слайд «мы ≠ нормоконтроль» |
| AGPL/SSPL соблазн «взять as-is» | high | Только паттерны; см. TOP10 |
| Claim «86%» у TimDoc | low | Не цитировать как факт |
| Нет открытого PDF-diff SOTA репо под РФ штампы | medium | Свой корпус + AeroBIM-донор важнее чужого IFC |

### Red Team
- Подмена постановки: жюри спрашивает «а СНиП?» → ловушка таблицы ТЗ; ответ ADR-0006.
- Подмена evidence: LLM пишет вердикт → уже закрыто ADR-0001; держать тесты.
- Supply chain: не vendor'ить SSPL «бесплатный Solibri».
- Social: команда «SOM» / «Casablanca» в поиске даст ложные сущности — не включать в слайды.

## 6. Что перенять / отвергнуть (сводка)

**Перенять**
- Слайд дифференциации от Цифрового нормоконтроля и TimDoc.
- On-prem / LLM-agnostic формулировки как у Коллегиума (без копирования продукта).
- Паттерны TOP10: noise filter, multi-metric confidence, CI gate, BCF-shaped finding.
- Мониторинг XML ИД Мосгосстройнадзора.

**Отвергнуть**
- Позиционирование «ИИ-экспертиза по СП».
- Cloud-only OCR/VLM в зачёт.
- Зависимость от AGPL/SSPL.
- Утверждения о финалистах без первоисточника.
