## Инварианты, которые держатся

Автомат не пишет `CONFIRMED_VIOLATION`: пайплайн поднимает `RuntimeError`,
если такой статус вышел из прогона. Единственная запись подтверждения —
`review`. `etalon_policy()` по умолчанию `sole_head`; любое другое значение,
включая мусор, даёт `strict`. Штамп при `SOLE_HEAD` не становится `APPROVED`.
Явный «не утв.» в пул головы не входит.

Свободный поиск оставляет только строки с группой доказательств и статусом
`CANDIDATE` или `SUSPICION` и переписывает их в `SUSPICION`.
`AUTO_NO_DIFFERENCE` нет в статусах провода протокола. На JSON участника
совпадение уходит как `NO_VIOLATION`. `ocr_text` в возможностях — `MEASURED`.
`run_directory` пишет `closes_gate_i/j/k/l: false`.
`USABILITY_RESULTS.md` пустой: пять строк «нет сессии».

Учебный комплект этим аудитом заново не прогонялся. Контракт прежний:
до выбора инспектора `PZ-001`, `KR-055`, `AR-041` в `CLARIFICATION_REQUIRED`,
после выбора — кандидаты, не подтверждённые нарушения.
