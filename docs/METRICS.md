# Метрики

Пороги раздела 14 ТЗ — минимумы приёмки, не результат Контура. Пока нет
frozen validation, размера выборки и нижней границы 95% интервала, репозиторий
не публикует их как достигнутые. Гейты I/J/K/L открыты.

| Контур | Порог приёмки |
|---|---|
| OCR | Character Accuracy не ниже 0,95. Рядом CER, coverage и доля нечитаемых зон |
| Ключевые поля | Exact Match не ниже 0,90 |
| Связка документов | не ниже 0,95 |
| Локализация | file_id и страница той же строки; полигон при IoU не ниже 0,50; доля не ниже 0,95 |
| Нарушения | Precision не ниже 0,90, Recall не ниже 0,80, F1 не ниже 0,85 |
| Ложные срабатывания | FPR не выше 0,10 |

Интервал для доли — Wilson. При n меньше 30 интервал Вальда не используется.
Разбиение train/validation/test — по `object_id`.

## Что посчитано

Публичный gold — не frozen validation. Матрица: 6 позитивов. Свободный поиск:
4 позитива. Единица совпадения в режиме по умолчанию `--match location` —
`object_id + parameter_code + location`. Номер помещения берётся как в
инвентаре (`140`), не как «помещение 140».

Повтор Тюменской после якоря шифра, запись в
[`GOLD_DIAGNOSIS.md`](GOLD_DIAGNOSIS.md): в режиме location матрица 0 из 6
и свободный поиск 0 из 4, оба abstain. `tz_recall_met` false,
`closes_gate_j` false. Это не порог ТЗ. В режиме `code` одно попадание
IOS4-079 — помещение 600, не строка эталона 012.

Повтор после метки с индексом и всех пар листов, тот же файл: оба режима
0 из 6 и 0 из 4, `unlabeled_positive` 0, помещение 600 в ответ не вышло.
Остановка снова «якорь или число не найдены». Нижняя граница Wilson для
recall при n=6 равна 0. Это публичная разметка разработки, не порог ТЗ.

Локализация этих строк не определена: у публичных проверок нет полигона
в инвентаре, знаменатель IoU пуст. `unlabeled_positive` — позитив без
метки `score_eligible`. В FPR такие строки и строки Новослободской
(`score_eligible=false`) не входят.

OCR на пилоте SILVER, не GOLD. Корпус `PDF_TEXT_LAYER`, n=5935, без
Речникова. Пороги 0,95 и 0,97 не взяты. Статус `ocr_text` — `MEASURED`.
Подробности — [`OCR_BAKEOFF.md`](OCR_BAKEOFF.md).

Покрытие матрицы — разбивка 55 / 72 / 1 / 4 из 132, не заявление, что все
проверки исполняются. Подсчёт объектов на плане остаётся
`extractor_missing`.

Замер k6 на `/status` (100 VU, 60 с, n=6000, p95 около 18 мс) — инженерный
прогон GitHub Actions. Это не production SLA.

Гейт K: рекордер кликов есть, пяти сессий нет. Порог «не больше 30 минут»
рекордером не закрыт.

Каждый результат несёт `matrix_version`, `dataset_version`, `model_version`,
`input_manifest_hash` и git SHA. `model_version` — имя доступного движка OCR,
иначе `none`.
