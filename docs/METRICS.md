# Метрики

Пороги раздела 14 считаются по нижней границе 95% интервала на frozen validation. Такой выборки в репозитории нет, поэтому ниже лежат замеры на публичном gold и на SILVER. Гейты I, J, K и L в приёмке ещё впереди.

| Контур | Порог приёмки |
|---|---|
| OCR | Character Accuracy не ниже 0,95. Рядом CER, coverage и доля нечитаемых зон |
| Ключевые поля | Exact Match не ниже 0,90 |
| Связка документов | не ниже 0,95 |
| Локализация | file_id и страница той же строки; полигон при IoU не ниже 0,50; доля не ниже 0,95 |
| Нарушения | Precision не ниже 0,90, Recall не ниже 0,80, F1 не ниже 0,85 |
| Ложные срабатывания | FPR не выше 0,10 |

Интервал для доли — Wilson. При n меньше 30 интервал Вальда не используется.
Разбиение train/validation/test — по `object_id`.

F1 — гармоническое среднее точности и полноты:

```text
F1 = 2 × Precision × Recall / (Precision + Recall)
```

На границе порогов, Precision = 0,90 и Recall = 0,80:

```text
F1 = 2 × 0,90 × 0,80 / (0,90 + 0,80) = 1,44 / 1,70 ≈ 0,847
```

Это ниже требуемых 0,85. Запас над порогом держим на точности: при полноте ровно 0,80 точность 0,907 уже даёт F1 0,85.

Интервал Wilson для доли p при n наблюдениях, z = 1,96:

```text
знаменатель = 1 + (z × z) / n
центр = (p + (z × z) / (2 × n)) / знаменатель
полуширина = z × квадратный корень из (p × (1 − p) / n + (z × z) / (4 × n × n)) / знаменатель
```

Нижняя граница — центр минус полуширина, верхняя — центр плюс полуширина.
Границы обрезаются до отрезка от 0 до 1. При n = 0 интервал равен [0; 1].
Порог FPR берётся по верхней границе. Остальные пороги раздела 14 — по нижней.
