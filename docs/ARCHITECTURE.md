# Архитектура

Контур сверяет загруженные ПД, РД и ИД по матрице из 132 параметров и
отдаёт инспектору кандидатов с доказательствами. Это не надзор без человека
и не сверка проекта со СНиП.

Три контура не складываются в один процент. Подробности —
[`TZ_SCORECARD.md`](TZ_SCORECARD.md) и [`METRICS.md`](METRICS.md).

| Контур | Что в нём | Сейчас |
|---|---|---|
| Code | Контракт, пайплайн, автотесты | 59 executable, 68 extractor_missing, 1 advisory, 4 source_missing |
| Acceptance | Пороги раздела 14 на frozen validation | не измерены. Гейты I/J/K/L открыты |
| Production | OIDC, TLS, живой РиН, УКЭП | не строятся до подачи |

## Как идёт запрос

Жюри открывает gateway (`:3000`). Он ограничивает размер тела, частоту
загрузки и отдаёт статику. Статусы находок он не пишет.

Ядро (`:8000`) проверяет JWT, роль и `object_id`. PDF разбирается в
дочернем процессе. DOCX отдаёт абзацы и таблицы. XML отдаёт текстовые
узлы, без схемы пояснительной записки и без внешних сущностей. Zip
раскрывается в PDF, DOCX и XML. 7z, rar и DWG не становятся тихим
пропуском: 7z и rar — `ARCHIVE_NOT_EXPANDED`, DWG — `UNSUPPORTED_FORMAT`.

Дальше детерминированный путь:

1. Голова редакции по шифру. Пустой шифр не прячет чужой том. Если штамп
   шифра не дал, ПД и РД с одним именем файла (без «кор», «изм» и «(1)»)
   становятся одной цепочкой: больший номер новее, «Корректировка №N» на
   титуле читается как номер. Один номер у разных файлов и смесь «изм» с
   «кор» — `CLARIFICATION_REQUIRED`. Акты ИД по имени не схлопываются.
   Единственная голова ПД без штампа сравнивается как `SOLE_HEAD`, штамп не
   становится утверждением. Явный «не утв.» эталоном не становится.
   На крупном листе надпись берётся из правого нижнего угла 190×70 мм:
   шифр, графа «Лист» и буква стадии П, Р или И. ГОСТ, сертификат и графа
   «Листов» в шифр и номер листа не попадают.
2. Экстрактор правила читает текст страницы. Размер вида 500×300 скалярное
   правило пропускает. Нет рабочего экстрактора — правило остаётся
   `extractor_missing` и нарушения не выдаёт. Сбой одного правила оставляет
   остальные строки.
3. Компаратор сравнивает значения. Разность десятичная. Триггер матрицы
   «уменьшение» или «увеличение» снимает кандидат противоположного знака;
   это отсутствие срабатывания, не `NEGATIVE_VERIFIED`. Прочее расхождение —
   `CANDIDATE` с `evidence_group_id`, SHA-256, страницей и polygon. Нет
   документа стадии — `MISSING_EVIDENCE`, это не нарушение.
4. Инспектор подтверждает или отклоняет. Только он пишет
   `CONFIRMED_VIOLATION`. Отклонение требует причину. Пачкой подтверждаются
   только отмеченные `CANDIDATE`.

Протокол JSON, DOCX, XML и PDF собирается из одного решения. В РиН уходит
mock-очередь. Подтверждение брокера не является ACK РиН.

## Где вердикт

Вердикт сравнения — код компаратора. Модель, если она появится, может
только предложить кандидата и черновик текста. Поле `finding_status` она
не пишет. Overlay нормы не меняет вердикт матрицы.

## Чего нет в зачётном прогоне

Внешние OCR, LLM и VLM. Облачный стенд по ссылке. Скрытый тест и подбор
порога по нему. Заявление, что все 132 параметра исполняются. Пять сессий
инспекторов. Промышленные OIDC, TLS, УКЭП и живой РиН.

Команда стенда и список «работает / не работает» — в [`README.md`](../README.md).
Пробелы — в [`KNOWN_GAPS.md`](KNOWN_GAPS.md).
