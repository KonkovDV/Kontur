# ADR-0015: нет сведений об утверждении — не эталон

Статус: принят. Заменяет пункт 1 ADR-0014. Остальные пункты ADR-0014
про две головы, «не утв.», РД/ИД и чужие шифры сохраняются.

## Контекст

26.09.2026 в рабочий контур передана сводная таблица ответов организатора.
По редакции: актуальная ПД — последняя применимая утверждённая редакция
цепочки predecessor/successor. Если сведения об утверждении отсутствуют
или цепочка противоречит, система возвращает `CLARIFICATION_REQUIRED` и
не формирует вывод о нарушении до решения инспектора.

ADR-0014 ставил единственной голове ПД без штампа `PACKAGE_DEFAULT`,
потому что письменного ответа не было.

## Решение

1. Голова ПД со `approval_status=UNKNOWN` не сравнивается, пока инспектор
   не выберет этот файл. Исход резолвера — `CLARIFICATION_REQUIRED`,
   причина «сведения об утверждении отсутствуют».
2. Выбор инспектора переводит такую голову в `APPROVED` с
   `approval_basis=INSPECTOR_SELECT`. Штамп паспорта не переписывается.
3. Явный «не утв.» по-прежнему нельзя перекрыть.
4. РД и ИД без графы «Утвердил» остаются пригодными к сравнению.
5. Значение `PACKAGE_DEFAULT` в перечислении сохраняется для уже
   записанных документов. Новый прогон его не назначает.

## Последствия

Отмена финализации по той же таблице доступна инспектору, администратору
и супервизору. Машина переход не делает. Причина обязательна.
