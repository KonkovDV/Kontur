# ADR-0014: ПД в комплекте — эталон, если нет явного отказа

Статус: принят. Заменяет правило эталона из ADR-0013. Источники индекса,
«В производство работ» и экспертизы по-прежнему не являются утверждением.

## Контекст

Письменного ответа жюри на вопрос 21 нет. На сессии 16.09 заказчик описал
эталон как документ, который участник положил в комплект как ПД, а не как
штамп, которого в поставленных томах часто нет. Доска оценивания требует
рабочий сценарий инспектора. Ждать новый источник утверждения до 29.09
нельзя.

## Решение

1. Одна голова шифра ПД без явного «не утв.» и без более новой редакции —
   эталон. `approval_status=APPROVED`, `approval_basis=PACKAGE_DEFAULT`.
   Графа «Утвердил» при этом не требуется и не подменяется: штамп паспорта
   остаётся тем, что прочитан.
2. Две и более редакции одного шифра ПД без порядка successor/predecessor —
   `CLARIFICATION_REQUIRED`. Инспектор по-прежнему может выбрать файл.
3. Явный «не утв.» / `NOT_APPROVED` не перекрывается ни комплектом, ни
   выбором инспектора.
4. РД и ИД не требуют утверждения. Берётся последняя редакция шифра.
   `NOT_APPROVED` блокирует сравнение. `PACKAGE_DEFAULT` на РД и ИД не ставится.
5. `TITLE_BLOCK` и `INSPECTOR_SELECT` сохраняются.
6. Поля индекса, штамп «В производство работ» и упоминание экспертизы
   по-прежнему не делают документ утверждённым.

Сообщение «эталон без признака утверждения» остаётся только для ПД, которая
не стала ни `TITLE_BLOCK`, ни `INSPECTOR_SELECT`, ни `PACKAGE_DEFAULT`.
Для РД и ИД сравнение останавливает только «не утв.».

## Последствия

- Прогон TRAIN_PUBLIC больше не обязан останавливаться на L4 из-за пустой
  графы «Утвердил» у единственной ПД. Это не попадание и не закрытие гейта J.
- Прогон процесса берёт голову каждой цепочки шифра, не последний файл стадии
  и не «один конфликт на всю стадию». Несколько файлов одного шифра без
  successor/predecessor дают `CLARIFICATION_REQUIRED`. Разные шифры — отдельные
  головы: правило привязывается к `document_kind` / разделу матрицы.
  Выбор инспектора чужой шифр не помечает заменённым и не перекрывает «не утв.».
  Штамп паспорта в `stamp_by_file_id` не переписывается в `PACKAGE_DEFAULT`.
- Harness `train_public` по-прежнему помечен `last_file_per_stage`. Снимок
  19.09 этим ADR не пересчитывается.
- `export_git_sha` в handoff этим ADR не обновляется.
