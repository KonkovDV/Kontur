# ADR-0017: единственная голова ПД без штампа — эталон с плашкой

Статус: принят 27.09.2026, решение R1 `sole_head`.
`KONTUR_ETALON_POLICY=strict` воспроизводит ADR-0015.

## Контекст

Публичный gold останавливался на «сведения об утверждении отсутствуют»:
после разделения пустых шифров у каждого тома своя голова, и штампа
«Утвердил» нет. Сравнение до помещений не доходило.

## Решение

1. По умолчанию `KONTUR_ETALON_POLICY=sole_head`. Неизвестное значение
   читается как `strict`.
2. Единственная голова ПД со статусом `UNKNOWN` становится эталоном с
   `approval_basis=SOLE_HEAD`. `approval_status` остаётся `UNKNOWN`.
   Штамп в `stamp_by_file_id` не переписывается.
3. Если в той же цепочке есть другая редакция `APPROVED`, черновик-голова
   эталоном не становится: `CLARIFICATION_REQUIRED`, причина
   «сведения об утверждении отсутствуют».
4. Две головы одного шифра без successor и явный «не утв.» по-прежнему
   `CLARIFICATION_REQUIRED`. Разные шифры — отдельные головы.
   Голова `SOLE_HEAD` не встаёт рядом с утверждённым файлом той же
   identity: сравнивается утверждённый.
5. Выбор инспектора по-прежнему `APPROVED` + `INSPECTOR_SELECT` и
   проверяется раньше sole head.
6. Карточка и протокол DOCX/PDF показывают «утверждение не подтверждено».
   Автомат пишет не выше `CANDIDATE`.

## Последствия

`strict` держит прежнюю остановку. Сравнение единственного тома без
штампа больше не ждёт инспектора. Это не доказательство утверждения.
